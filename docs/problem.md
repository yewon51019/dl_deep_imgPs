# 문제 정의

> 실험 기록에서 확인되는 내용만 적었습니다. "팀 확인 필요"는 기록에 근거가 없어 팀이 채워야 하는 부분입니다.

## 풀려는 문제

알약 사진만으로 어떤 정신건강의학과 약인지 알아냅니다.

## 대상과 상황

- **대상 사용자:** 팀 확인 필요
- **사용 상황:** 팀 확인 필요
- **지금 풀고 있는 방법의 한계:** 팀 확인 필요

## 왜 어려운가 (실험에서 확인)

| 어려움 | 내용 |
|---|---|
| 각인이 잘 안 보임 | 음각 글자는 조명에 따라 일부 획이 사라짐. 흰 원형 알약에서 특히 어려움 |
| 방향을 모름 | 알약이 아무 방향으로 놓임. 읽기 모델은 뒤집힌 글자도 높은 확신도로 읽음 |
| 각인 모양이 다양함 | 가장자리를 따라 휜 글자(아리셉트정), 절취선으로 나뉜 글자 |
| 같은 각인의 약 | 각인과 겉모습이 같은 약은 사진으로 가를 수 없음. 약 목록 1,211종 중 445종이 각인을 공유 |
| 데이터 오류 | 라벨 앞뒤 뒤바뀜, 사진과 라벨 불일치가 일부 있음 |

## 성공의 의미 (제안, 팀 확인 필요)

틀린 약을 하나만 보여 주는 일이 가장 위험합니다. 그래서 정확도와 함께 **약 1개로 확정했는데 틀린 비율**을 봅니다.

최종 평가 432장에서 약 1개 확정은 170장이고 그중 4장이 틀렸습니다. 원인은 아직 분석하지 않았습니다.
