# 테스트 계획 및 결과

## 데이터 나누기

약 단위로 나눠 같은 약이 학습과 평가에 함께 들어가지 않게 합니다.

| 묶음 | 약 / 사진 | 쓰임 |
|---|---|---|
| 학습용 | 323종 4,296장 | 모델 학습 (검증 65종 포함, 모델마다 일부를 학습에 씀) |
| 검증 | 65종 828장 | 설정값 고르기 |
| 개발 | 36종 468장 | 방식 비교 |
| 평가 A | 26종 288장 | 1차 공식 평가 (전체 사진, 카메라 60°·90°) |
| 평가 B | 36종 432장 | 최종 공식 평가 (자른 사진, 카메라 75°·90°) |

## 규칙

1. 방식은 개발·검증으로만 고릅니다. 평가는 마지막에 한 번만 합니다.
2. 평가 전에 방식을 기록하고, 평가 결과를 보고 공식 방식을 바꾸지 않습니다.
3. 새 규칙의 채택 기준은 실행 전에 정합니다: 좋아진 사진 − 나빠진 사진이 검증 +5장 이상, 개발 0장 이상. 나중 시험부터는 틀린 답 증가가 맞은 수 증가를 넘지 않아야 합니다.
4. 기존 결과를 덮어쓰지 않고, 라벨 문제가 있어도 공식 점수는 고치지 않습니다.
5. 어려운 사진만 골라 비교한 결과로 결정하지 않습니다. 전체에서 다시 잽니다.

## 지표

약 정확도(판정 없음은 오답), 판정 없음, 틀림, macro 정밀도·재현율·F1, 읽기 완전일치, 후보 포함률, 약 1개 확정 중 틀림. 긴 / 그 외, 카메라 각도별로도 봅니다.

## 결과를 읽을 때 주의

- 평가 B는 평가 A와 약 19종, 파일 이름 114장이 겹치고, A의 오류를 분석한 뒤 읽기 방식을 바꿨습니다. 완전히 독립적인 평가가 아닙니다.
- pft1은 평가를 본 뒤 기본으로 정했습니다.
- 검증 65종 중 27종은 글자 찾기 모델 1차 학습에 사용된 약입니다. 검증 숫자는 조금 낙관적일 수 있습니다. 개발 36종은 어떤 학습에도 없습니다.
- 평가 A 60.8%(base)는 입력 조건이 달라 위 표와 직접 비교할 수 없습니다.
- 오답 73장은 약 9종에 몰립니다. 약 하나가 12장이므로 숫자가 크게 움직입니다.
