# 제품 요구사항

> 상태: 초안. 기능 규칙은 실험에서 쓴 값이고, 화면·서비스 관련 내용은 정해지지 않았습니다.

## 기능 요구사항

| 번호 | 요구사항 | 기준 |
|---|---|---|
| F1 | 사진 한 장을 받아 약 후보 순위를 만든다 | `docs/tech-spec.md`의 최종 방식 |
| F2 | 1등이 0.95 이상이고 2등과 0.1 이상 차이 나면 약 1개만 보여 준다 | 최종 점수 기준 |
| F3 | 그 밖에는 후보를 보여 준다. 1등 동점이면 동점인 약 전부, 동점이 아니면 1등, 2등, 2등과 동점인 약 | 5개 이하일 때 |
| F4 | 후보가 5개를 넘으면 다른 면 사진이나 다시 찍기를 요청한다 | |
| F5 | 다른 면 사진을 받으면 두 장으로 다시 판별한다 | 요청 흐름 미구현 |
| F6 | 판별 근거를 보여 준다: 읽은 글자, 약의 각인 | 제안 |

## 성능 참고값

공식 평가 세트 B (432장·36종, 공식 방식 pft1 + TF3, 표시는 pft1 기준).

| 항목 | 값 |
|---|---|
| 약 정확도 | 83.1% (pft1만 82.9%) |
| 약 1개 확정 | 170장, 그중 틀림 4장 |
| 후보 표시 | 251장, 후보 안에 정답 94.4% |
| 다른 면·다시 찍기 요청 | 11장 (2.5%) |
| 한 장 처리 시간 | 약 350ms (GTX 1070 Ti, 겉모습 모델 미포함, 모델 불러오는 시간 별도) |

앱의 목표값은 정해지지 않았습니다. 위 숫자를 약속으로 쓰지 마세요. 세트 B는 완전히 독립적인 평가가 아니며, pft1은 평가를 본 뒤 정했습니다.

## 지켜야 할 조건

- AI Hub 사진과 사진이 든 결과물을 공개 저장소에 올리지 않습니다.
- 약 판별은 라벨이나 파일 이름의 정보(회전각 등)를 쓰지 않습니다.
- 판정 없음과 후보 표시는 "모르면 모른다고 말하기"입니다. 억지로 약 하나를 답하지 않습니다.

## 미정 (팀 확인 필요)

- 앱 형태, 실행 위치 (폰 / 서버), GPU 없는 환경의 속도
- 사용자가 사진을 넣는 방법과 알약 자르기
- 약 목록 갱신 방법과 주기
- 의료 관련 안내 문구, 개인정보 처리 (사진 저장 여부)
