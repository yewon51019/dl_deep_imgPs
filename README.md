# 정신건강의학과 약 분류 AI

AI융합캡스톤디자인 팀 프로젝트 (김태린, 남예원, 장혜정, 조하은)

알약 사진에서 각인(새겨진 글자)을 읽고, 약 목록과 비교해 약 이름을 찾는 프로그램을 만듭니다. 지금은 실험을 마친 단계이고, 앱 코드는 아직 없습니다.

## 현재 결과

| 평가 (공식, 사전 기록한 방식) | 사진 · 약 | 약 정확도 | 비고 |
|---|---|---|---|
| 평가 세트 B (최종) | 432장 · 36종 | **83.1%** | 후보 약 1,211종, 자른 사진 |
| 평가 세트 A (1차) | 288장 · 26종 | 60.8% | 전체 사진, 카메라 60° 포함. 입력 조건이 달라 위 숫자와 직접 비교 불가 |

이후 기본 방식은 규칙을 뺀 `pft1`입니다 (세트 B 82.9%). 평가를 본 뒤 정했으므로 새 사진으로 확인해야 합니다. 자세한 내용은 [docs/test-plan.md](docs/test-plan.md)를 보세요.

## 실행 환경

Windows + VS Code + PowerShell, 파이썬 3.12, NVIDIA GPU (GTX 1070 Ti, CUDA 12.6 빌드). 실험 스크립트는 저장소 맨 위에서 실행하고, 실행 방법은 각 파일 맨 위 주석에 있습니다. 기존 결과를 덮어쓰지 않도록 새 실행에는 새 이름을 씁니다.

글자 찾기(Paddle)와 읽기(PyTorch)는 라이브러리가 충돌해 환경을 나눕니다. 설치 방법은 `AGENTS.md` 8장을 보세요.
